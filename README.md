# AdmitPro - College Admission Portal 🎓

> A modern, responsive, and feature-rich **College Admission Portal** web application built with a single-file architecture (**HTML5, CSS3, and Vanilla JavaScript**). Designed to simplify and digitize the student admissions lifecycle—from initial registration and multi-step application filing to merit ranking and printable offer letters.

---

## 🌟 Key Features & Modules

* 📊 **Dashboard Overview:** Real-time tracking of total applicants, under-review submissions, confirmed admissions, rejections, and a live activity feed.
* 👤 **Student Registration:** Onboard new applicants capturing complete personal details, dates of birth, contact information, and degree program preferences.
* 🧙‍♂️ **Multi-Step Application Wizard:** A guided 3-step application pipeline ensuring clean separation between applicant selection, qualifying board scores, and final submission.
* 🔍 **Advanced Application Registry:** Instant text-search by student name combined with multi-criteria dropdown filters for application status and degree course.
* 👁️ **Detailed Record View:** Deep-dive view of individual candidate portfolios, credentials, and reviewer comments.
* 📂 **Simulated Document Upload:** Management and tracking interface for essential verification documents (10th/12th marksheets, passport photos, transfer certificates, and identity proofs).
* ⚖️ **Application Review Panel:** Administrative controls to review academic performance, shortlist candidates, or reject submissions instantly.
* 🏆 **Merit List Engine:** Automated composite scoring engine (`(Board Score + Entrance Score) / 2`) that ranks applicants and automatically generates merit lists.
* 🎓 **Admission Confirmation & Offer Letters:** Seat confirmation controls with an integrated **Printable Official Offer Letter generator** styled for clean physical or PDF printing.
* 📈 **Reports & Analytics:** Course-wise distribution breakdowns, demographic insights, and a **CSV Report Export** utility.
* 🌙 **Dark Mode Toggle:** Fully responsive glassmorphism design supporting seamless switching between light and dark themes.
* 💾 **Local Storage Persistence:** Client-side persistence ensuring data is saved across browser sessions without requiring an external database backend.

## 🚀 Quick Start / Running Locally

Since this is a lightweight, frontend-only project with **no backend or database server required**, getting it running takes seconds:

1. **Clone or Download** the repository to your local machine.
2. Ensure you have the single-file source saved as **`index.html`** in your project directory.
3. **Open the file** in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari) by double-clicking it or using a local development server like VS Code's *Live Server* extension.

```bash
# Optional: Open directly via terminal (macOS)
open index.html

# Optional: Open directly via terminal (Linux)
xdg-open index.html

```
